## 首次启动

1. 先进入设置页面，授予必要权限。不同设备的权限页面可能略有差异，请按照系统提示完成授权。
2. 回到媒体流页面。首次启动时，如果当前已有正在播放的媒体流，AirLyrics 会自动选中它；如果没有正在播放的媒体流，则不会选中任何对象，之后需要手动选择。
3. 进入悬浮窗页面，点击下方的显示按钮，即可显示悬浮窗。之后可以在此页面根据自己的喜好调整悬浮窗样式。

## 选择媒体流

在此页面中，可以选择需要监听的媒体。

如果没有媒体显示，请先检查相关权限是否已经开启。

首次启动时，AirLyrics 只会在当前已有播放中媒体流时自动选中它。如果开启悬浮窗后无法正常显示歌词，请先确认是否已经选中媒体流。

## 配置悬浮窗

此页面包含悬浮窗相关配置。这里对一些特殊配置做出说明：

1. **歌词偏移**：只会对当前歌曲生效，并且会自动保存。下次播放同一首歌时，会继续应用该偏移设置。
2. **逐字歌词（卡拉 OK 歌词）**：只能通过本地导入使用。如果有这个需求，可以自行搜索并下载对应歌词后导入。
3. **动画效果中的高亮颜色**：特指逐字歌词中已经显示部分的颜色。

此页面中的设置都会自动保存在本地，悬浮窗位置也同样具有记忆功能。

## 设置

### 权限

理论上来说，必要权限只有 **悬浮窗权限** 和 **通知访问权限**（用于监听媒体）。

通知权限主要用于在通知栏生成控制入口，方便在特殊情况下（比如游戏中）快速隐藏悬浮窗，或者调整悬浮窗位置。

可以根据自己的使用情况选择开启或关闭。

### 歌词获取设置

基础功能不做过多说明，这里只说明几个需要注意的地方：

1. **歌词保存目录**  
   建议使用默认保存目录。如果选择自定义目录，请确保 AirLyrics 可以通过系统文件选择器访问该目录。

2. **移除 App 时会移除默认目录下的文件**  
   这也会清除所有保存在默认目录中的歌词，请谨慎操作。

3. **歌词格式**  
   App 内置了歌词快速修改窗口。如果想了解歌词格式，请参考相关说明。

4. **逐字歌词导入**  
   如果导入了一份逐字歌词，而这首歌没有普通歌词，App 会自动根据逐字歌词生成一份普通歌词。  
   因此，非常建议在导入逐字歌词前，先移除这首歌已有的本地歌词。

5. **删除逐字歌词选项**  
   只有在当前歌词包含逐字歌词时，才会显示这个选项。
