v1.0.5 - 2026-06-28

Fixed
- Prevented duplicate page rendering during cold start.
- Restored floating lyrics correctly after AirLyrics is removed from recent apps and reopened.
- Kept lyric edits attached to the original track when playback changes mid-edit.
- Unified lyric import and format validation when editing lyrics.

Changed
- Made native builds reproducible and improved F-Droid compatibility.

v1.0.4 - 2026-06-07

Fixed
- Respected the Android navigation bar inset so bottom tabs are no longer clipped by three-button navigation.
- Kept the recent local lyrics refresh button visible when the inline help hint is shown.

Changed
- The changelog dialog now shows only the current release by default, with a button to view the full changelog.

v1.0.3 - 2026-06-06

Added
- Normal LRC import now recognizes same-timestamp lines as original lyrics and translations.
- Word-by-word lyrics import now recognizes same-timestamp translation lines and uses them when generating normal lyrics for songs without existing normal lyrics.

Changed
- Updated lyrics format documentation for translated normal LRC and translated word-by-word LRC.
- Polished project documentation and README to reflect the stable actively maintained project status.

Fixed
- Prevented floating window style changes from rebuilding the floating settings page when visible, so sliders and color controls stay usable while editing.
- Reduced flicker when manually refreshing current-song lyrics and recent local lyrics by keeping existing content visible while refreshing.

v1.0.2 - 2026-06-05

Changed
- Refactored MainActivity to reduce its responsibilities and make the main app structure easier to maintain.

v1.0.1 - 2026-06-02

Fixed
- Kept the floating lyrics UI and service state in sync after visibility changes.
- Prevented stalled lyrics lookups from blocking newer lyrics requests.
- Cleaned up NotificationListener lifecycle handling and debounced media session rescans.
- Improved floating notification visibility action text and error feedback.
- Reduced main-thread I/O risk during lyrics and service state handling.

Changed
- Release builds can now produce unsigned APKs when no local release keystore is configured.
- Incomplete release signing configuration still fails early to avoid accidental broken signed builds.

v1.0.0 - 2026-05-31

Added
- Initial APK release.
- Floating synced lyrics display for Android.
- Current media playback detection through notification access.
- Online lyrics search and local lyrics import.
- User guide and project documentation.
